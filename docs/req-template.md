## قواعد دائمة (Standing Rules)

1. **الملفات المسموحة صريحة وملزمة.**
2. **الأدلة الميكانيكية إلزامية قبل أي "تم":** `tsc --noEmit` + `npm run build` + `git diff --stat` فعلية.
3. **كل REQ يحتوي (حتى لو مختصر):** AC مرقّمة + Edge Cases + تحقق بدليل.
4. **Commit واحد واضح لكل REQ.**
5. **قبل أي REQ جديد:** حدّث `/docs/backlog.md` (In Progress)، وبعده `/docs/changelog.md`.
6. **ممنوع خلط feature/fix مع refactor/dependency غير مطلوب في نفس REQ.**
7. **[جديد — 2026-09-12 — INC-2026-09-12] أي REQ يلمس `firestore.rules` يجب أن يحتوي AC إضافي إلزامي:**
   > تشغيل `firebase deploy --only firestore:rules` ولصق مخرجاته الطرفية كدليل إضافي إلى جانب tsc/build/git diff.
   > تغيير القواعد لا يُعتبر مكتملًا حتى يتم تأكيد النشر الحي — نجاح البناء المحلي لا يثبت ما هو مُطبّق في الإنتاج.
